# Model

Technical papers by Jason Edelman and Claude. The model itself is public code (`model/lec-core.cjs`), and the same code runs the [tools](/tools/) and the chat agent. Every input is a scenario unless a paper cites its source. These are mechanism models, not forecasts. They show which design choices move risk and wealth, and by roughly how much.
